# Java Fundamentals ☕ and Academic Projects 📑

A collection of Java programming exercises and academic projects developed during the second-semester "Object-Oriented Programming with Java" course using the NetBeans IDE.

## Topics Covered

- Arithmetic
- Variables and Data Types
- Conditional Statements
- Loops
- Arrays
- Methods
- Object-Oriented Programming
- Java Swing GUI

## Projects Included

- Cashier System
- Student Pass/Fail Checker
- Average Grade Calculator
- Height and Weight Converter
- Mini-Mart System
- Payroll Management System
